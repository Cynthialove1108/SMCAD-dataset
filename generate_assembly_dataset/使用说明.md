# 装配特征数据集生成器 - 使用说明

## 概述

本工具是基于原SMCAD钣金特征数据集代码改写的**装配特征参数化建模与数据集生成系统**,具有以下特点:

### ✨ 核心改进

1. **多样化底层基体**
   - ❌ 原代码:仅支持板类零件
   - ✅ 新系统:支持6种基体类型(板、块、轴、箱体、支架、法兰)

2. **丰富的装配特征**
   - ❌ 原代码:钣金加工特征(折弯、冲孔等)
   - ✅ 新系统:装配连接特征(螺纹连接、销连接、键连接等)

3. **自动标注系统**
   - ✅ 保持:每个B-rep面自动标注特征类型
   - ✅ 增强:支持减材和增材特征的区分标注

4. **参数化与批量生成**
   - ✅ 保持:完全参数驱动,自动批量生成
   - ✅ 增强:碰撞检测,智能特征布局

## 快速开始

### 1. 环境准备

```bash
# 安装PythonOCC (建议使用conda)
conda install -c conda-forge pythonocc-core

# 或使用pip
pip install pythonocc-core
```

### 2. 运行测试

```bash
cd generate_assembly_dataset
python test_generation.py
```

预期输出:
```
✓ Base part generation test passed
✓ Assembly feature generation test passed
✓ Random feature generation test passed
✓ Complete part generation test passed
ALL TESTS PASSED ✓
```

会生成 `test_assembly_part.step` 文件。

### 3. 查看示例

```bash
python example_usage.py
```

生成5组示例文件:
- `example_1_plate.step` - 简单板件
- `example_2_shaft.step` - 轴类零件
- `example_3_flange.step` - 法兰
- `example_4_random_*.step` - 10个随机零件
- `example_5_custom.step` - 自定义特征

### 4. 批量生成数据集

```bash
python generate_dataset.py
```

默认生成100个零件,保存在 `assembly_dataset_output/` 目录。

## 功能详解

### 1. 基体类型(6种)

#### 1.1 板类零件 (PlateBase)
```python
from assembly_features.base_parts import PlateBase

plate = PlateBase(length=100, width=80, thickness=10)
# 适用于:平面装配,常规螺栓连接
```

#### 1.2 块类零件 (BlockBase)
```python
block = BlockBase(length=80, width=60, height=50)
# 适用于:多面特征,复杂装配
```

#### 1.3 轴类零件 (ShaftBase)
```python
shaft = ShaftBase(diameter=40, length=150)
# 适用于:键槽,径向孔,传动连接
```

#### 1.4 箱体零件 (BoxBase)
```python
box = BoxBase(outer_length=100, outer_width=80,
              outer_height=60, wall_thickness=5)
# 适用于:壁面装配,封装结构
```

#### 1.5 支架零件 (BracketBase)
```python
bracket = BracketBase(base_length=100, base_width=80,
                      vertical_height=60)
# 适用于:L型连接,双面装配
```

#### 1.6 法兰零件 (FlangeBase)
```python
flange = FlangeBase(outer_diameter=150, inner_diameter=60,
                    thickness=20)
# 适用于:圆周分布螺栓,管道连接
```

### 2. 装配特征(10种)

#### 减材特征(7种)

##### 2.1 螺纹通孔
```python
from assembly_features.assembly_features import ThreadedHole
from OCC.Core.gp import gp_Pnt

hole = ThreadedHole(
    diameter=8,        # M8螺纹
    depth=25,          # 深度25mm
    position=gp_Pnt(20, 30, 10)
)
```

##### 2.2 螺纹盲孔
```python
blind_hole = ThreadedBlindHole(diameter=10, depth=20)
# 用于:不需贯通的螺纹连接
```

##### 2.3 销孔
```python
pin_hole = PinHole(diameter=6, depth=30)
# 用于:定位销,传动销
```

##### 2.4 键槽
```python
key_slot = KeySlot(width=8, length=28, depth=5)
# 用于:轴键连接,传递扭矩
```

##### 2.5 沉孔
```python
counterbore = Counterbore(
    hole_diameter=10,      # 螺栓孔
    bore_diameter=18,      # 沉孔直径
    bore_depth=6           # 沉孔深度
)
# 用于:内六角螺栓连接
```

##### 2.6 沉头孔
```python
countersink = Countersink(
    hole_diameter=8,
    sink_diameter=16,
    sink_angle=90
)
# 用于:平头/沉头螺钉
```

##### 2.7 定位孔
```python
positioning = PositioningHole(diameter=3, depth=15)
# 用于:精密定位,装配基准
```

#### 增材特征(3种)

##### 2.8 螺栓
```python
bolt = Bolt(shaft_diameter=10, shaft_length=40)
# 简化螺栓模型(圆柱头+杆)
```

##### 2.9 销钉
```python
pin = Pin(diameter=6, length=25)
# 圆柱销
```

##### 2.10 键
```python
key = Key(width=8, height=5, length=28)
# 平键
```

### 3. 自动标注系统

每个面自动标注格式:
- 基体面: `base_{类型}` (如 `base_plate`)
- 特征面: `{特征类型}_{ID}` (如 `threaded_hole_0`)

示例:
```python
labels = generator.generate_labels()
# 输出: {face1: "base_plate", face2: "threaded_hole_0", ...}
```

在CAD软件中查看STEP文件时,每个面的名称即为标签。

## 使用示例

### 示例1: 简单四孔板

```python
from assembly_features.base_parts import PlateBase
from generate_dataset import AssemblyPartGenerator, save_shape_to_step

# 创建120x100x12的板
base = PlateBase(length=120, width=100, thickness=12)

# 生成器:4个螺纹孔
generator = AssemblyPartGenerator(
    base_part=base,
    num_subtractive_features=4,
    num_additive_features=0
)

# 生成并保存
generator.generate_features()
combined = generator.combine_features()
labels = generator.generate_labels()
save_shape_to_step("my_plate.step", combined, labels)
```

### 示例2: 完全随机生成

```python
# 随机基体 + 随机特征数量 + 随机位置
generator = AssemblyPartGenerator()
generator.generate_features()
combined = generator.combine_features()
labels = generator.generate_labels()

# 查看生成了什么
summary = generator.get_feature_summary()
print(f"基体类型: {summary['base_type']}")
print(f"特征: {summary['subtractive_types']}")
```

### 示例3: 批量生成1000个零件

编辑 `generate_dataset.py`:
```python
OUTPUT_DIR = "./my_dataset"
NUM_PARTS = 1000
```

运行:
```bash

```

## 常见问题

### Q1: 生成失败怎么办?
A: 布尔运算可能因几何复杂度失败,程序会自动跳过。可减少特征数量。

### Q2: 如何查看生成的零件?
A: 使用FreeCAD (免费):
```bash
# Ubuntu/Debian
sudo apt install freecad
freecad example_1_plate.step
```

### Q3: 标签不准确?
A: 当前使用简化标注算法。对于精确标注,可集成更严格的几何比较。

### Q4: 如何添加新特征?
A:
1. 在 `assembly_features.py` 继承 `AssemblyFeature`
2. 实现 `_create_shape()` 方法
3. 添加到工厂函数

示例:
```python
class MyNewFeature(AssemblyFeature):
    def __init__(self, param1, param2):
        super().__init__("my_new_feature")
        self.param1 = param1
        # ...
        self._create_shape()

    def _create_shape(self):
        # 使用OCC API创建形状
        self.shape = ...
```

### Q5: 生成速度慢?
A:
- 单个零件: 0.5-2秒
- 减少特征数量可加速
- 可并行生成(修改主脚本使用多进程)

## 技术细节

### 底层几何内核
使用OpenCASCADE (通过PythonOCC绑定):
- 精确B-rep建模
- 鲁棒的布尔运算
- 标准STEP导出

### 参数化方法
所有特征完全由数值参数定义:
```
输入参数 → 几何构建 → 布尔运算 → 标注 → STEP导出
```

### 碰撞检测
简化的2D投影检测:
- 在特征放置前检查
- 保证最小间距
- 最多尝试50次随机位置
